# USB-CAM

[![Android](https://img.shields.io/badge/Platform-Android-green.svg)](https://www.android.com)
[![Jetpack Compose](https://img.shields.io/badge/Jetpack%20Compose-UI-blue.svg)](https://developer.android.com/jetpack/compose)
[![Kotlin](https://img.shields.io/badge/Language-Kotlin-purple.svg)](https://kotlinlang.org)

**USB-CAM** is a modern, simple Android application designed to monitor kids (or external USB cameras) on Android devices and HeadUnits. It automatically detects and connects to available cameras (including USB UVC cameras), provides immersive full-screen viewing with zero information loss, supports Picture-in-Picture (PiP), image mirroring, gesture-based zoom & pan, and multi-camera switching.

---

## ✨ Key Features

- **🚀 Automatic Camera Detection**: Automatically detects and launches the primary camera upon startup.
- **🔌 USB UVC Camera Support**: Powered by CameraX and `libausbc` for robust external USB camera integration.
- **🖥️ Full-Screen Immersive View with Zero Loss**: Loads scaled to completely fill the screen while preserving 100% of the image data — allowing you to freely drag/pan and pinch-to-zoom across the entire uncropped frame.
- **🪞 Image Mirroring (Flip X & Y)**: Real-time horizontal and vertical mirroring options controllable via the settings menu.
- **🖼️ Picture-in-Picture (PiP) Mode**: Seamlessly transition to PiP mode when leaving the app, with clean auto-hiding of overlay controls.
- **🔄 Multi-Camera Support**: Easily switch between multiple connected cameras from the settings menu.
